M2ZPicks Appwrite TODO
======================

Goal
----
Keep the public contact page simple. The form now only asks for useful fields and submits to one collection based on the selected goal.

Important Appwrite rule
-----------------------
For each collection below, allow public/guest users to CREATE documents only. Do not allow public READ, UPDATE, or DELETE access.

1) Existing collection: ad-leads
--------------------------------
Collection name: Ad Leads
Collection ID: ad-leads
Purpose: Advertisement and sponsorship requests.

Keep these existing columns:
- fullName                 string, required
- workEmail                email or string, required
- companyBrandName         string, required
- websiteUrl               url or string, required
- promotionDetails         string, required, long text/textarea
- promotionType            string, required
- targetAudienceGoal       string, required, long text/textarea

Add only these useful columns:
- budgetRange              string, required
- consent                  boolean, required

Remove/skip these older suggested ad columns for now because the simplified form no longer sends them:
- rolePosition
- preferredStartDate
- campaignDuration
- targetGeography
- hasCreatives
- mediaUrl
- heardFrom
- additionalInfo
- sourceUrl
- status
